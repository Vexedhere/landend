# Mythical Studios — Portfolio

A responsive, single-file portfolio landing page for Mythical Studios.

## Features
- Responsive desktop and mobile navigation
- Neo-brutalist-inspired dark visual identity with purple, lime and orange accents
- Studio introduction, project directory and category filters
- Search overlay (also available with Ctrl/Cmd + K)
- Capabilities, community, updates and contact sections
- Instagram and YouTube links
- Copyable Minecraft server address
- Live Bedrock server status check via mcstatus.io
- Scroll reveal animations and reduced-motion support

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

The site is plain HTML/CSS/JavaScript; no build step or package installation is required.
